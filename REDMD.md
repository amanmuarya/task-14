# Number Analyzer

## Objective
This project contains a JavaScript program designed to perform various mathematical operatons and checks on a given number It serves as a comprehensive tool to analyze the properties of a number using proper control structures (loops and conditionals).

## Features

The program includes a main function `analyzeNumber(n)` that performs the following tasks for any given number n
Sum of First 'n' Numbers:   Calculaes the total sum from 1 up to`n.
Multipliction Table:  
 Prints the multiplication table of n (from 1 to 10).
Prime Number Check:
  Determines if `n` is a prime number (divisible only by 1 and itself).
Factors Calculation:
  Finds and prints all whole number factors of `n.
Sum of Digits:
 Calculates the sum of all individual digits within the number 
(e.g., 139 => 1 + 3 + 9 = 13).
Armstrong Number Check:
Checks if the number is an Armstrong number (where the sum of its own digits each raised to the power of the number of digits equals the original number itself).
